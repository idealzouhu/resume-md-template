### 概述

本模板在标准 Markdown 之上，通过 [markdown-it-container](https://github.com/markdown-it/markdown-it-container) 扩展以下围栏容器：

| 容器 | 用途 |
|------|------|
| `::: photo` | 单独插入证件照 |
| `::: resume-header` | 顶栏：左侧个人信息（Markdown）+ 右侧证件照 |
| `::: job-row` | 同一行内分栏：时间 / 职位 / 公司等（独占行 `---` 分段） |

此外支持**内联**占位符 `[[icon:名称]]`（见下文「内联图标」），用于在正文或链接旁插入与文字同色的 SVG 图标。

围栏写法统一为三行：`::: 名称`、中间内容、收尾 `:::`。

---

### 图片路径写在哪？

所有图片路径均相对于**生成的 HTML**，即项目中的 `output/{basename}.html`（如 `resumes/default.md` 对应 `output/default.html`）。

示例：

- 照片在仓库根目录 `photo.jpg` → 写 `../photo.jpg`
- 照片在 `assets/id.jpg` → 写 `../assets/id.jpg`

内联图标对应的矢量文件位于仓库内 `assets/icons/`（如 `blog.svg`），由生成脚本读入并**内联**进 HTML，无需在 Markdown 里写 `../assets/icons/...` 路径；若你自行增删图标文件，需同步修改 `generate.mjs` 中的内置名称表。

---

### `::: photo`

容器内写**一行非空路径**（相对路径或图片 URL）。首条非空行作为 `<img>` 的 `src`。

```markdown
::: photo
../assets/id.jpg
:::
```

渲染为 `<figure class="resume-photo">…</figure>`，样式由当前 `--theme` 指定的主题 CSS 中的 `.resume-photo` 控制。

---

### `::: resume-header`

用于简历**最上方**：左侧为 Markdown（常见写法为 `# 姓名`、一行简介与链接），右侧为证件照。

容器内用**单独一行**的分隔符 `---` 切成两段：

1. **分隔线以上**：左侧个人信息，按 Markdown 正常解析。
2. **分隔线以下**：两行约定——第一行必须为字面量 `photo`，第二行为图片路径。

**有照片时的 HTML 结构**（生成脚本会加修饰 class `resume-header--has-photo`）：

- 若分隔线以上**首段非空行**为一级标题 `# 姓名`，则 `h1` 单独通栏渲染，其余信息进入 `resume-header__main`，与照片同处 `resume-header__row` 一行（信息与照片顶对齐）。
- 若无一级标题，则全部信息留在 `resume-header__main`，`__row` 内仅照片；**建议有照片时首行写 `# 姓名`**，与木及编辑器的顶栏版式一致。

```html
<div class="resume-header resume-header--has-photo">
  <h1>姓名</h1>
  <div class="resume-header__row">
    <div class="resume-header__main">…简介与链接…</div>
    <figure class="resume-photo"><img … /></figure>
  </div>
</div>
```

与木及编辑器 `:::left` / 空 `:::right` + 运行时 JS 定位 `#rs-avatar` 不同：本模板用 `---` + `photo` + 路径，在**生成期**输出静态 HTML/CSS，打印与离线浏览更稳定。无照片时仍为扁平结构（`h1` 在 `resume-header__main` 内）。

```markdown
::: resume-header
# 张三

前端工程师 · 示例城市 | [邮箱](mailto:you@example.com)

---
photo
../assets/id.jpg
:::

## 技能

…
```

顶栏之后的章节（如 `## 技能`）仍为普通单栏流式排版，无需再包容器。

### 内联图标 `[[icon:名称]]`

在任意支持**内联** Markdown 的位置（含 `::: resume-header` 左侧正文、`::: job-row` 各栏）可写：

```markdown
[[icon:blog]] [[icon:github]] [[icon:email]] [[icon:phone]]
```

- **名称**仅允许小写字母、数字与连字符 `-`，当前内置：`blog`、`github`、`email`、`phone`，与仓库中 `assets/icons/*.svg` 一一对应。
- 图标为内联 `<svg>`，`fill` 使用 `currentColor`，放在 `[文字](url)` 内时会随链接颜色变化（含暗色与打印样式）。
- **未知名称**不会被替换，原文保留，并在生成时于控制台输出警告。
- **勿在反引号内**写该语法（行内代码中的 `[[icon:...]]` 不应被当作图标解析；若出现异常，请避免在代码片段中使用相同字面量）。

与顶栏结合的示例：

```markdown
::: resume-header
# 张三

[[icon:email]][邮箱](mailto:you@example.com) · [[icon:github]][GitHub](https://github.com/example)

---
photo
../assets/id.jpg
:::
```

### `::: job-row`

用于**工作经历、项目**等标题行：同一行内左 / 中 / 右排列（常见为时间、职位、公司）。

规则：容器内用**独占一行**且该行仅含 `---`（与顶栏分段字符相同）作为栏分界。

- **两栏**：一行 `---` 分成左、右两段。
- **三栏**：两行 `---` 分成左、中、右三段。
- 每一段支持**内联** Markdown（加粗、链接等），可多行合并为一段后再参与分栏。

```markdown
::: job-row
2020.01 – 至今
---
**高级工程师**
---
某某科技有限公司
:::
```

渲染为带 `job-row`、`job-row__cell` 等 class 的 `<div>` / `<span>`，样式见当前主题 CSS 中的 `.job-row`。

**教育背景两栏示例**（代替木及 `::: left` / `::: right`）：

```markdown
::: job-row
**华侨大学 - 计算机科学与技术**
---
**2019.09 - 2022.07**
:::
```

左栏为学校与专业，右栏为起止时间；与工作经历三栏写法相同，只是省略中间一栏。

### 源码注释（可选）

若需在 `.md` 里写说明且不出现在网页中，可使用引用定义式注释（通常不产生可见 HTML）：

```markdown
[//]: # '证件照路径相对于 output/{basename}.html'
```

### 实现说明（供查阅）

生成脚本 `generate.mjs` 在解析后会对 `photo`、`resume-header`、`job-row` 等容器做折叠，输出语义化 HTML，避免路径或栏位原文被重复渲染成段落。顶栏内用于解析左侧 Markdown 的实例**不注册** `resume-header`，以避免嵌套同名容器导致递归；`job-row` 各栏文本使用单独的内联解析实例。

内联图标：启动时用 `fs.readFileSync` 载入 `assets/icons/{blog,github,email,phone}.svg`，在 **三个** markdown-it 实例（主文档 `md`、顶栏/分栏折叠用 `mdPhotoOnly`、栏内联用 `mdInline`）上注册同一内联规则；规则挂在 `inline` 的 `backticks` 之后，将 `[[icon:名称]]` 替换为带 `resume-icon` class 的 `<span>` 包裹的内联 SVG。样式见当前主题 CSS 中的 `.resume-icon`。
