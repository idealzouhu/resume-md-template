### 概述

本模板在标准 Markdown 之上，通过 [markdown-it-container](https://github.com/markdown-it/markdown-it-container) 扩展以下围栏容器：

| 容器 | 用途 |
|------|------|
| `::: photo` | 单独插入证件照 |
| `::: resume-header` | 顶栏：左侧个人信息（Markdown）+ 右侧证件照 |
| `::: job-row` | 同一行内分栏：时间 / 职位 / 公司等（独占行 `---` 分段） |

围栏写法统一为三行：`::: 名称`、中间内容、收尾 `:::`。

---

### 图片路径写在哪？

所有图片路径均相对于**生成的 HTML**，即项目中的 `output/resume.html`。

示例：

- 照片在仓库根目录 `photo.jpg` → 写 `../photo.jpg`
- 照片在 `assets/id.jpg` → 写 `../assets/id.jpg`

---

### `::: photo`

容器内写**一行非空路径**（相对路径或图片 URL）。首条非空行作为 `<img>` 的 `src`。

```markdown
::: photo
../assets/id.jpg
:::
```

渲染为 `<figure class="resume-photo">…</figure>`，样式由 `style.css` 中的 `.resume-photo` 控制。

---

### `::: resume-header`

用于简历**最上方**：左侧为 Markdown（常见写法为 `# 姓名`、一行简介与链接），右侧为证件照。

容器内用**单独一行**的分隔符 `---` 切成两段：

1. **分隔线以上**：左侧个人信息，按 Markdown 正常解析。
2. **分隔线以下**：两行约定——第一行必须为字面量 `photo`，第二行为图片路径。

```markdown
::: resume-header
# 张三

前端工程师 · 示例城市 | [邮箱](mailto:you@example.com)

---
photo
../assets/id.jpg
:::

## 技能

…
```

顶栏之后的章节（如 `## 技能`）仍为普通单栏流式排版，无需再包容器。

---

### `::: job-row`

用于**工作经历、项目**等标题行：同一行内左 / 中 / 右排列（常见为时间、职位、公司）。

规则：容器内用**独占一行**且该行仅含 `---`（与顶栏分段字符相同）作为栏分界。

- **两栏**：一行 `---` 分成左、右两段。
- **三栏**：两行 `---` 分成左、中、右三段。
- 每一段支持**内联** Markdown（加粗、链接等），可多行合并为一段后再参与分栏。

```markdown
::: job-row
2020.01 – 至今
---
**高级工程师**
---
某某科技有限公司
:::
```

渲染为带 `job-row`、`job-row__cell` 等 class 的 `<div>` / `<span>`，样式见 `style.css` 中的 `.job-row`。

---

### 源码注释（可选）

若需在 `.md` 里写说明且不出现在网页中，可使用引用定义式注释（通常不产生可见 HTML）：

```markdown
[//]: # '证件照路径相对于 output/resume.html'
```

---

### 实现说明（供查阅）

生成脚本 `generate.mjs` 在解析后会对 `photo`、`resume-header`、`job-row` 等容器做折叠，输出语义化 HTML，避免路径或栏位原文被重复渲染成段落。顶栏内用于解析左侧 Markdown 的实例**不注册** `resume-header`，以避免嵌套同名容器导致递归；`job-row` 各栏文本使用单独的内联解析实例。
